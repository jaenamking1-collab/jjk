Threads 팔로우 강조 — 설치 방법 (PC 크롬·엣지, 1분)

1. 이 zip 파일을 우클릭 → "모두 압축 풀기"로 풉니다. (폴더는 지우지 말고 그대로 두세요)
2. 크롬 주소창에 chrome://extensions 를 입력해 엽니다. (엣지는 edge://extensions)
3. 오른쪽 위 "개발자 모드"를 켭니다.
4. "압축해제된 확장 프로그램을 로드합니다"를 누르고, 풀어 둔 threads-follow-highlight 폴더를 선택합니다.
5. Threads(threads.com)를 새로고침하면, 내가 팔로우한 사람의 프로필 사진에 노란 링이 깜빡입니다.

* 처음 한 번: 내 프로필 > 팔로잉 목록을 열어 끝까지 내려 주세요. 그 목록을 기억해서 링을 답니다.
* 왼쪽 아래 노란 글씨에 기억한 팔로잉 수가 보입니다. 새로 팔로우하면 자동으로 늘어납니다.
* 폰 앱에서는 쓸 수 없고, PC 웹에서만 됩니다.
* 크롬을 켤 때 "개발자 모드 확장 프로그램" 경고가 뜰 수 있는데 그냥 닫으면 됩니다.
