# TIGER(미래에셋) 분배금 공지 받기 — 막힌 경로 뚫기 의뢰

## 목표
구글 Apps Script 서버(UrlFetchApp)가 미래에셋 TIGER ETF 분배금 공지 목록과 공시일을
**PC 없이** 매일 받아 오게 하는 방법을 찾아 주세요. 개인 배당 기록 앱용이고, 공개된 공지만 읽습니다.

## 지금 막힌 곳 (모두 실측)
1. Apps Script(구글 서버) → 미래에셋 공지 페이지: HTTP 403, 차단 페이지 1,350자. 국내 PC 에선 200. 2026-10-27 저녁부터.
2. GitHub Actions 러너 → 미래에셋: 403(해외 서버를 봇으로 차단하는 것으로 보임).
3. Apps Script → FunETF 공개 API: 403. 국내 PC 에선 열림.

## 지금 쓰는 대체 경로
- 예탁결제원(SEIBRO): 구글 서버에서 열림. 금액은 원본과 88/88 일치. 단점: 공시일 없음(추정값은 쓰지 않음).
- PC 중계: 국내 PC 가 1시간마다 미래에셋 목록을 받아 GitHub 에 커밋, 서버가 raw 로 읽음. 단점: PC 가 꺼져 있으면 늦음.

## 해 볼 것 (순서대로)
1. 구글·GitHub 말고 **다른 서버 위치**에서 열리는지: Cloudflare Workers(이미 사용 중, jjk.distributionjn.workers.dev), 국내 리전 클라우드(오라클·AWS 서울 무료 등급).
2. 공시일·분배율이 있는 **다른 공개 출처**: KRX 정보데이터시스템, 전자공시(DART·KIND), 네이버 금융, 증권사 공개 API, 미래에셋 공식 RSS·앱 API.
3. 안 되면 무엇이 몇 번 응답 코드로 막혔는지 표로.
