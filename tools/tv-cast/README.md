# TV 자막 전송

`실행.cmd`를 두 번 누르면 조작 화면이 열립니다. Node.js 20.3 이상과 자막 합성(libass)을 지원하는 FFmpeg/FFprobe가 필요합니다. 개발한 PC에는 둘 다 설치되어 있습니다.

동영상 선택 → 자막 확인(같은 이름 자동 검색) → TV 찾기 → 자막 합치고 TV에서 재생. TV 전원을 켜고 같은 네트워크에 연결해야 합니다. Windows가 네트워크 허용을 물으면 본인의 **개인 네트워크**에서 허용합니다. Miracast는 필요하지 않습니다. DLNA AVTransport를 지원하는 TV가 대상입니다.

SRT·SMI·ASS·SSA·VTT 외부 자막을 H.264/AAC MP4 영상에 합성합니다. UTF-8·한국어 CP949·UTF-16LE를 읽습니다. 최대 1080p이며, 기본 영상과 첫 오디오 트랙을 사용합니다. 원본의 HDR·다중 오디오 보존용 프로그램은 아닙니다. 준비 시간이 필요하고 임시 디스크에 영상 크기만큼 공간이 필요합니다.

변환 결과는 `%TEMP%\jjk-tv-cast`에만 저장합니다. 같은 입력은 재사용하며, 공간을 비우려면 프로그램 종료 후 이 폴더를 삭제할 수 있습니다. 원본·TV 주소·미디어 로그를 저장소에 기록하지 않습니다.

화면은 명령 수락, TV의 HTTP 영상 요청, 실제 화면 확인을 구분합니다. TV 요청 시각은 재생 전체가 정상이라는 보증은 아닙니다. TV가 안 보이면 게스트 와이파이의 기기 격리, VPN, 방화벽, TV 연결 허용을 확인합니다. 재생 동안 프로그램을 켜두고, 끝날 때 **프로그램 종료**를 누릅니다.

검증: `node --test tools/tv-cast/core.test.js tools/tv-cast/convert.test.js`. 실제 TV 화면의 자막과 소리는 현장에서 별도로 확인해야 합니다.
