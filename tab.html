1. 연결 시험

pkg install -y curl && curl -s -o /dev/null -w "%{http_code}\n" -A Mozilla/5.0 -d "firstIndex=0&listCnt=20&pageIndex=1" https://investments.miraeasset.com/tigeretf/ko/customer/notice/list.ajax

복사한 뒤 Termux 화면을 길게 눌러 붙여넣고 엔터. 끝에 나오는 숫자를 알려 주세요.

2. 고치기 (curl 실행 안 될 때)

apt update && apt full-upgrade -y -o Dpkg::Options::=--force-confnew

붙여넣고 엔터. 끝나면 위 1번을 다시 한 번 복사해 실행하세요.

3. 프로그램 받고 읽기 시험

pkg install -y python git && git clone --depth 1 https://github.com/jaenamking1-collab/jjk ~/jjk && cd ~/jjk/tools && python -c "import tiger_relay as t;i=t.fetch_list();print(len(i),i[0]['date'])"

붙여넣고 엔터. 끝에 나오는 숫자 두 개를 알려 주세요.

4. 올리는 열쇠 만들기

여기를 눌러 열기

열리면 이것만 확인하세요.
① Repository access → Only select repositories → jjk 하나만 고름
② 맨 아래 Generate token 누름
③ 나온 긴 글자(github_pat_로 시작)를 복사 (이 화면을 벗어나면 다시 못 봅니다)

5. 열쇠 넣기

cd ~/jjk && git config user.name jaenamking1-collab && git config user.email jaenamking1-collab@users.noreply.github.com && read -rsp "열쇠 붙여넣기: " T && git remote set-url origin https://jaenamking1-collab:$T@github.com/jaenamking1-collab/jjk.git && unset T && echo 넣음

Termux에 붙여넣고 엔터 → "열쇠 붙여넣기:" 가 뜨면 방금 복사한 열쇠를 길게 눌러 붙여넣고 엔터. 글자는 안 보이는 게 정상입니다.

6. 올리기 시험

cd ~/jjk && git status --short | head -5; git remote get-url origin | wc -c; python tools/tiger_relay.py --force; tail -3 tools/tiger_relay.log

붙여넣고 엔터. 마지막에 나오는 3줄을 알려 주세요(또는 화면을 찍어 주세요).

8. 정리하고 다시 돌리기

cd ~/jjk && pkill -f tab_loop.sh; git rebase --abort 2>/dev/null; git stash clear; git fetch -q origin && git reset -q --hard origin/main && (nohup sh tools/tab_loop.sh >/dev/null 2>&1 &); sleep 2; git status --short | head -3; ps -ef | grep -c "[t]ab_loop"

붙여넣고 엔터. 마지막 숫자 1이면 돌고 있는 것입니다. (7번은 이미 했으니 건너뛰세요)

7. 자동으로 돌리기

먼저 한 번만: 탭 설정 → 앱 → Termux → 배터리 → 제한 없음.

cd ~/jjk && git pull -q --rebase --autostash && (nohup sh tools/tab_loop.sh >/dev/null 2>&1 &) ; sleep 2; ps -ef | grep -c "[t]ab_loop"

붙여넣고 엔터. 숫자 1이 나오면 돌고 있는 것입니다.
