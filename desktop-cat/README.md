# 바탕화면 고양이 (윈도우)

작은 고양이가 바탕화면 아이콘·창 윗변·작업표시줄, 그리고 열린 창 속 그림·글자 윗선 위를 걸어 다닙니다.

## 실행
1. 파이썬 3.9 이상을 설치합니다(설치할 때 "Add python.exe to PATH" 체크).
2. `run.bat` 을 더블클릭합니다. 처음 한 번은 `pillow`·`numpy` 를 자동으로 설치합니다.
3. 작업표시줄 오른쪽 트레이에 있는 고양이 아이콘을 누르면 메뉴가 뜹니다: 부르기 / 숨기기 / 크기 / 색 / 윈도우 켤 때 자동 실행 / 종료.

## 하는 일
- 아이콘 위를 걷고, 옆 아이콘·아래 아이콘으로 점프하고, 멀리도 뜁니다(가끔 다른 모니터까지).
- 크롬 같은 창을 열면 창 윗변과 창 속 그림·글자 윗선을 발판으로 씁니다(고양이 주변을 0.6초마다 화면 캡처해서 찾고, 저장하지 않습니다).
- 창을 끌면 위에 있던 고양이도 같이 움직입니다. 창이 사라지면 떨어집니다.
- 기본 그림체는 **사용자가 준 참고 그림 그대로**(`sprites/` 20컷). 동작마다 알맞은 그림을 고르고 통통 튀기·기울이기·숨쉬기로 움직입니다.
  트레이 메뉴 '색'에서 코드로 그린 고양이(하양·치즈·회색·검정)로도 바꿀 수 있습니다.
- 그림을 더 받으면(같은 5×4 칸 시트) `pip install "rembg[cpu]" scipy` 후 `python make_sprites.py 시트.png` 로 다시 오립니다.
  걷기 여러 장·꼬리 위치별 그림처럼 장면이 늘수록 움직임이 자연스러워집니다.
- 동작 66가지 + 묶음 행동:
  - **걸음** 걷기·살금살금·종종걸음·깡충깡충·뒷걸음·우다다
  - **점프** 옆·아래·먼 곳(다른 모니터), 연속 점프, 구석 탐험, 아래로 뛰어내리기
  - **매달리기** 점프하다 아슬아슬 매달리기, 가장자리에서 미끄러져 매달리기, 떨어지다 붙잡기, 대롱대롱·버둥버둥·한 발로 흔들기, 낑낑 기어오르기, 손 놓고 떨어지기
  - **벽(창 옆면)** 타고 오르기, 벽으로 점프해 달라붙기, 멈칫했다 주르륵, 박박 긁기, 모서리 뒤에서 몰래 보기
  - **쉬기** 그루밍, 귀 긁기, 앞발 핥기, 세수, 다리 들고 핥기, 식빵, 다리 쭉 엎드리기, 웅크려·벌러덩·옆으로 자기, 하품, 기지개, 뒷다리 쭉, 두리번, 고개 갸웃, 궁금해하기, 멍때리기, 얌전히 앉기, 뒷모습, 에취, 몸 털기, 킁킁, 꾹꾹이, 꼬리 탁탁, 아래 내려다보기, 앞발 대롱, 삐지기
  - **놀이** 기분 좋기, 하트 안기, 별 보기, 생선 장난감, 모자 쓰기, 박스 안에 쏙, 나비 잡기, 냥냥펀치, 야옹, 깍깍, 배 보이기, 데굴데굴, 꼬리 쫓기, 빙글 돌고 눕기, 사냥 모드
  - **반응** 높은 데서 쿵 → 몸 털기, 창이 휙 움직이면 납작 버팀, 발판이 사라지면 어리둥절
- 마우스가 다가오면 놀라서 폴짝 뛴 뒤 다다다 도망칩니다. 가만히 두면 쳐다보다가 하트를 보내거나, 살금살금 다가와 덮칩니다.

## 파일
| 파일 | 역할 |
|---|---|
| `desktop_cat.py` | 투명 창·트레이 메뉴·메인 루프 (윈도우 전용) |
| `win_world.py` | 모니터·창·아이콘 위치, 화면 속 윤곽선 찾기 |
| `cat_brain.py` | 행동·점프 궤적·도망 (OS 무관) |
| `cat_render.py` | 관절로 고양이 그리기 (OS 무관) |
| `preview.py` | 가짜 바탕화면에서 돌려 GIF 로 저장 — 맥에서도 됩니다 |

문제가 생기면 같은 폴더의 `desktop_cat.log` 에 기록이 남습니다.
