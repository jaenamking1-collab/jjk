# 바탕화면 고양이 (윈도우)

작은 고양이가 바탕화면 아이콘·창 윗변·작업표시줄, 그리고 열린 창 속 그림·글자 윗선 위를 걸어 다닙니다.

## 실행
1. 파이썬 3.9 이상을 설치합니다(설치할 때 "Add python.exe to PATH" 체크).
2. `run.bat` 을 더블클릭합니다. 처음 한 번은 `pillow`·`numpy` 를 자동으로 설치합니다.
3. 작업표시줄 오른쪽 트레이에 있는 고양이 아이콘을 누르면 메뉴가 뜹니다: 부르기 / 숨기기 / 크기 / 색 / 윈도우 켤 때 자동 실행 / 종료.

## 하는 일
- 아이콘 위를 걷고, 옆 아이콘·아래 아이콘으로 점프하고, 멀리도 뜁니다(가끔 다른 모니터까지).
- 크롬 같은 창을 열면 창 윗변과 창 속 그림·글자 윗선을 발판으로 씁니다(고양이 주변을 0.6초마다 화면 캡처해서 찾고, 저장하지 않습니다).
- 창을 끌면 위에 있던 고양이도 같이 움직입니다. 창이 사라지면 떨어집니다.
- 쉴 때 하는 행동 12가지: 그루밍, 귀 긁기, 앞발 핥기, 세수, 엎드리기, 아래 내려다보기, 하품, 기지개, 두리번, 자기, 꾹꾹이, 꼬리 탁탁.
- 마우스가 다가오면 놀라서 폴짝 뛴 뒤 반대쪽으로 다다다 도망칩니다. 멀찍이 있으면 마우스를 쳐다봅니다.

## 파일
| 파일 | 역할 |
|---|---|
| `desktop_cat.py` | 투명 창·트레이 메뉴·메인 루프 (윈도우 전용) |
| `win_world.py` | 모니터·창·아이콘 위치, 화면 속 윤곽선 찾기 |
| `cat_brain.py` | 행동·점프 궤적·도망 (OS 무관) |
| `cat_render.py` | 관절로 고양이 그리기 (OS 무관) |
| `preview.py` | 가짜 바탕화면에서 돌려 GIF 로 저장 — 맥에서도 됩니다 |

문제가 생기면 같은 폴더의 `desktop_cat.log` 에 기록이 남습니다.
