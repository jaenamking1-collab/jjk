# 고양이 영상 모으기 (Seedance 무료 크레딧으로 하루에 조금씩)

2026-10-07 사용자 결정: fal.ai 는 선충전이라 쓰지 않고, **드리미나(Dreamina) 같은 Seedance 무료 크레딧**으로 매일 조금씩 만든다.
사용자가 mp4 를 채팅에 올리면 → 어느 세션이든 아래 '처리 방법'대로 장면을 뽑아 `sprites/` 에 넣고 `sprite_render.py` 의 `ART` 를 바꾼다.

## 만들 순서 (위에서부터 — 눈에 많이 띄는 순)

| # | 동작 | 입력 그림 (`video_in/`) | 상태 |

| 7 | 정면으로 걸어오기 | `walk_front.png` | ⬜ |

## 넣을 문장 (공통 뒷부분은 꼭 붙인다)

2026-10-07 고침: 처음 문장(2번 뛰기)은 '반복'·'하지 말 것'이 없어 영상 AI 가 달리다 두 발로 점프하는 식으로 이야기를 지어냈다.
→ **같은 동작을 일정하게 반복 / 제자리(러닝머신처럼) / 서거나 뛰지 않음** 을 꼭 적는다.

공통(1~5, 7번 끝에 붙임): `처음부터 끝까지 같은 동작이 일정한 속도로 계속 반복된다. 고양이는 화면 가운데 제자리에 머문다(러닝머신 위처럼). 카메라 고정, 확대·이동 없음. 단색 짙은 남색 배경, 그림자·글자 없음.`

1. (잘 됨, 그대로) 하얀 아기 고양이가 제자리에서 자연스럽게 걷는다. 옆모습, 오른쪽을 본다. 네 다리가 모두 보이고 번갈아 움직인다. 꼬리는 살랑살랑.
2. 하얀 아기 고양이가 러닝머신 위에서처럼 제자리에서 빠르게 달린다. 옆모습, 오른쪽을 본다. 네 발로 계속 달리며 앞발과 뒷발이 번갈아 쭉 뻗었다 모이는 달리기 동작을 반복한다. 두 발로 서거나 점프하지 않는다. 몸은 수평을 유지하고 꼬리는 뒤로 뻗는다.
3. 하얀 아기 고양이가 정면을 보고 얌전히 앉아 있다. 앉은 자세는 그대로이고 꼬리만 천천히 좌우로 흔들며, 가끔 눈을 깜빡이고 귀를 쫑긋한다. 일어서거나 걷지 않는다.
4. 하얀 아기 고양이가 앉은 채로 한쪽 앞발을 들어 핥고, 그 발로 얼굴을 쓱 닦은 뒤 발을 내린다. 이 동작을 천천히 반복한다. 일어서거나 자리를 옮기지 않는다.
5. 하얀 아기 고양이가 웅크린 채 깊이 잠들어 있다. 자세는 그대로이고 숨 쉴 때마다 배가 살짝 부풀었다 가라앉으며, 가끔 귀나 꼬리 끝이 움찔한다. 눈을 뜨거나 일어나지 않는다.
6. (공통 줄 대신 끝에 `카메라 고정, 확대·이동 없음. 단색 짙은 남색 배경, 그림자·글자 없음.`) 하얀 아기 고양이가 옆모습으로 오른쪽을 보고 있다. 몸을 낮추고 엉덩이를 두세 번 실룩거린 뒤, 네 발로 힘차게 위로 한 번 뛰어올랐다가 같은 자리에 네 발로 착지한다. 두 발로 서지 않는다.
7. 하얀 아기 고양이가 정면(카메라 쪽)을 보고 러닝머신 위에서처럼 제자리에서 걷는다. 앞발과 뒷발이 번갈아 움직이고 머리는 살짝 좌우로 흔들린다. 몸 크기와 위치는 그대로이고 카메라에 가까워지지 않는다.

설정: 길이 4~5초(길면 다른 동작을 끼워 넣는다), 화질은 낮아도 됨, 가로 16:9. 엉뚱하면 같은 문장으로 2~3번 뽑아 나은 것을 쓴다(1초만 제대로 반복돼도 그 구간만 쓴다).

## 처리 방법 (세션용)
**한 줄로:** `python make_sprites.py v_이름=영상.mp4:시작장면:장수:방향` — 시작장면·장수는 아래 2번처럼 찾는다.
캔바 AI 영상은 1280×720·24fps·8초였다. 앞부분은 꼬리가 펴지거나 카메라가 다가와 흔들리니 3초 뒤부터 고른다.
배경 제거는 AI(rembg) 대신 **배경색 거리(크로마키)** 를 쓴다 — AI 는 장면마다 꼬리를 지웠다 살렸다 했다.

1. `ffmpeg -i in.mp4 frames/%04d.png` 로 전부 뽑는다(컨테이너에 ffmpeg 있음).
2. 반복 구간: 시작 장면과 가장 비슷한 뒤쪽 장면을 찾아 한 주기만 남긴다(걷기·뛰기). 앉기·자기는 전체를 쓰고 앞뒤를 섞어 반복되게.
3. 배경 제거: `make_sprites.py` 의 `cut_detected` 와 같은 방식(rembg isnet-general-use + 짙은 배경색 걷어내기). 칸 크기는 모든 장면 같게(`STRIP` 처럼).
4. 장수: 걷기·뛰기 12~16장, 나머지 12~24장으로 솎는다. `ART` 에 `('step', [...])`(걸음 동작) 또는 `('cycle', [...], fps)`.
5. GIF 로 먼저 보여주고, 사용자가 좋다고 하면 `main` → exe 자동 빌드.
