# /blueprint — 실행 계획 및 구현 로드맵 제공

사용자가 `/blueprint <질문>` 으로 보냈다. 뒤의 질문(인자)에 **이 형식으로만** 답한다.

- 목표 → 구성 → 구현 순서 → 검증 방법으로 실행 계획을 짠다.
- 존댓말은 그대로 지킨다(CLAUDE.md 0번).
- 형식만 바꾼다. 작업 범위·검증·커밋 규칙은 그대로다 — 짧게 답하라는 뜻이지 일을 덜 하라는 뜻이 아니다.
- 이 모드는 **그 메시지 한 번**에만 적용된다. 다음 메시지에 모드가 없으면 평소대로 답한다.
