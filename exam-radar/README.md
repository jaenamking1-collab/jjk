# 시험감독 레이더 (베타)

갤럭시탭용 안드로이드 앱. 시험장에서 **원래 없던 와이파이 핫스팟·블루투스 기기**가 나타나면 깜빡임·진동으로 알리고, 대략 거리와 가까워짐/멀어짐으로 찾게 돕는다.

- 설치 파일: `exam-radar-beta.apk` (태블릿에서 받아 누르기 → "출처를 알 수 없는 앱" 허용)
- 빌드: `gradle assembleRelease` (서명 열쇠는 공개 저장소 밖, `EXAM_RADAR_KEYSTORE`·`EXAM_RADAR_KEYPASS` 환경변수)
- 신호는 기기 안에서만 다루며 어디에도 보내지 않는다.
