# 📈 바탕화면 실시간 시세 위젯 — 사용 설명서

바탕화면 한쪽에 작은 창을 띄워 두고 **국내 주식·ETF, 미국 주식, 코인, 환율, 지수**를 실시간으로 보여 주는 프로그램입니다.
아래쪽에는 **월배당 ETF 운용사 8곳(KODEX·TIGER·ACE·PLUS·RISE·SOL·HANARO·KIWOOM)의 분배금 공지판**이 붙어 있어서, 새 공지가 뜨면 바로 알 수 있습니다.

- 무료이고, 회원가입·로그인이 없습니다.
- 파이썬 같은 다른 프로그램을 따로 깔 필요가 없습니다. 파일 하나만 받으면 됩니다.
- 켤 때마다 **자동으로 최신 버전**이 됩니다. 다시 받을 필요가 없습니다.
- 윈도우 10·11 전용입니다. 맥과 휴대폰에서는 돌아가지 않습니다.

> [그림 1] 바탕화면 오른쪽 아래에 떠 있는 위젯 전체 모습

## 1. 설치하기 (1분)

### ① 파일 받기
아래 주소에서 **`RealtimeTicker.exe`** 를 받습니다.

👉 https://github.com/jaenamking1-collab/jjk/releases/download/ticker/RealtimeTicker.exe

(받은 파일 이름은 `RealtimeTicker.exe` 입니다. 원하시면 `실시간시세.exe` 로 이름을 바꿔도 됩니다.)

### ② 처음 실행할 때 파란 경고창이 뜹니다 — 정상입니다
개인이 만든 프로그램이라 마이크로소프트 인증서가 없어서, 처음 한 번은 **"Windows의 PC 보호"** 창이 뜹니다.

1. 창 안의 **`추가 정보`** 글자를 누릅니다.
2. 아래에 생긴 **`실행`** 버튼을 누릅니다.

한 번 실행하고 나면 다음부터는 이 창이 뜨지 않습니다.

> [그림 2] "Windows의 PC 보호" 창 → '추가 정보' 클릭 → '실행' 버튼

※ 백신 프로그램이 막으면 '허용' 또는 '예외로 두기'를 눌러 주세요.

### ③ 끝
화면 **오른쪽 아래**에 위젯이 뜹니다. 처음에는 코스피·코덱스200·환율·비트코인 같은 예시 종목이 들어 있습니다.

### (선택) 바탕화면 아이콘 · 컴퓨터 켤 때 자동 실행
- **바탕화면 아이콘**: `RealtimeTicker.exe` 를 바탕화면에 두거나, 마우스 오른쪽 → `바로 가기 만들기`.
- **컴퓨터 켤 때 자동으로 뜨게**:
  1. 키보드 `윈도우키 + R` → `shell:startup` 입력 → 확인
  2. 열린 폴더에 `RealtimeTicker.exe` 의 **바로 가기**를 넣습니다. (exe 파일 자체를 옮기지 말고 바로 가기를 넣으세요)

> [그림 3] 윈도우키+R 실행창에 shell:startup 을 입력한 모습

## 2. 화면 보는 법

> [그림 4] 위젯 확대 — 각 부분에 번호 표시 (①종목 이름 ②현재가 ③등락률 ④구분선 ⑤⚙ 톱니 ⑥공지판 ⑦숨기기 버튼)

| 부분 | 설명 |
|---|---|
| 종목 이름 | 내가 정한 이름이 나옵니다. |
| 현재가 | 몇 초마다 새로 바뀝니다. |
| 등락률 | 어제보다 **오르면 빨강, 내리면 파랑**입니다(국내식). |

| 구분선 | 줄을 누르면 그 묶음이 **접히고 펼쳐집니다.** |
| 종목 줄 누르기 | 오늘 오르내린 **금액·전일 값**이 함께 펼쳐집니다. 다시 누르면 접힙니다. |

## 3. 분배금 공지판 (월배당 투자자용)

> [그림 5] 공지판 확대 — 월중/월말 두 묶음, 회사 이름 칸 8개씩, 불 켜진 칸과 깜박이는 칸, 맨 아래 최근 공지 한 줄

```
월중 │ KODEX  TIGER  ACE    PLUS
     │ RISE   SOL    HANARO KIWOOM
월말 │ KODEX  TIGER  ACE    PLUS
     │ RISE   SOL    HANARO KIWOOM
10.12 RISE 10월 월중배당
```

- **월중**(달 중순 기준) 회차와 **월말** 회차를 따로 보여 줍니다. 칸마다 운용사 이름이 적혀 있습니다.
- **불이 켜진 칸** = 그 회사가 이번 회차 분배금을 **공시했고, 아직 지급일이 안 지난** 상태입니다.
- **깜박이는 칸** = **새로 뜬 공지**입니다. 누르면 그 회사 공지 원문이 열리고 깜박임이 멈춥니다.
- 지급일이 지나면 불이 저절로 꺼집니다.
- 맨 아래 한 줄은 **가장 최근 공지**입니다.

**언제 반영되나요?** 운용사가 공지를 올린 뒤 **보통 30분~45분 안에** 위젯에 나타납니다. 위젯을 **켜 둔 채로 두면 저절로 들어옵니다.** 껐다 켤 필요가 없습니다.
(껐다 켜면 그 순간 이미 켜져 있던 칸은 '본 것'으로 처리돼서 깜박이지 않습니다. 켜 두시는 쪽이 새 공지를 놓치지 않습니다.)

## 4. 내 종목으로 바꾸기

**⚙ 톱니**를 누르면 설정창이 열립니다. (위젯에 마우스를 올리면 보입니다. 위젯 위에서 마우스 오른쪽 → `설정` 도 됩니다)

> [그림 6] 설정창 — 종목 목록 입력칸, 항상 위에 표시, 바탕 투명·글자 진하기 막대, 바탕색, 갱신(초), 저장 버튼

목록 칸에 **한 줄에 하나씩** 적고 `저장`을 누르면 끝입니다.

### 적는 법

| 무엇을 | 이렇게 적기 | 예시 |
|---|---|---|
| 국내 주식·ETF | **6자리 종목코드** | `005930` (삼성전자), `0005A0` 처럼 영문 섞인 코드도 됩니다 |
| 이름 붙이기 | `코드=이름` | `069500=코덱스200` |
| 지수 | `KOSPI`, `KOSDAQ` | `KOSPI=코스피` |
| 미국 주식 | 티커 | `AAPL`, `NVDA`, `SCHD` |
| 환율 | `USDKRW=X` | `USDKRW=X=환율` |
| 코인(원화) | `코인-KRW` | `BTC-KRW=비트코인`, `XRP-KRW` |
| 구분선 | `---` | 묶음을 나눕니다 |

예시 목록:
```
KOSPI=코스피
USDKRW=X=환율
---
069500=코덱스200
005930=삼성전자
---
SCHD
BTC-KRW=비트코인
```

### 목표가 알림 (선택)
줄 끝에 **`@가격`** 을 붙이면 그 값에 닿을 때 반짝입니다.

| 적는 법 | 뜻 |
|---|---|
| `005930=삼성전자@90000` | 9만 원에 닿으면 ★ 표시 + 반짝임 |
| `005930=삼성전자@85000,90000` | 여러 단계 목표. 아직 안 닿은 가장 가까운 목표까지 남은 %를 보여 줍니다 |
| `005930=삼성전자@90000,v70000` | 앞에 **v** 를 붙이면 **하한선**. 7만 원 아래로 내려가면 ▼ 경고 + 반짝임 |

### 그 밖의 설정
- **항상 위에 표시**: 다른 창 아래로 숨지 않게 합니다.
- **바탕 투명 / 글자 진하기**: 막대를 끌어서 조절합니다. 바탕을 0으로 하면 글자만 떠 있습니다.
- **바탕색**: 색 칸을 눌러 고릅니다.
- **갱신(초)**: 몇 초마다 새로 볼지. 기본 5초, 최소 3초입니다.

## 6. 자주 묻는 질문

**Q. 바이러스 아닌가요? 경고창이 떠서 걱정돼요.**
개인이 만든 프로그램은 마이크로소프트에 돈을 내고 인증서를 사지 않으면 누구 것이든 이 경고가 뜹니다. 이 프로그램은 시세 사이트(네이버·야후·빗썸·업비트 등)와 공지 데이터만 읽어 오고, **내 컴퓨터의 파일이나 계좌 정보에는 손대지 않습니다.** 로그인·비밀번호를 묻지도 않습니다.

**Q. 증권사 계좌와 연결되나요?**
아니요. 시세만 보여 주는 프로그램입니다. 계좌·보유 수량은 전혀 모릅니다.

**Q. 값이 `err` 이나 `…` 로 나와요.**
- 종목코드가 맞는지 확인하세요(국내는 6자리).
- 회사·학교 인터넷은 일부 시세 사이트를 막는 경우가 있습니다. 잠시 기다리면 다른 경로로 다시 받아 옵니다.

**Q. 숫자가 장중인데도 안 바뀌어요.**
오른쪽 클릭 → `새로고침`. 그래도 그대로면 인터넷 연결을 확인해 주세요.

**Q. 업데이트는 어떻게 하나요?**
따로 하실 것 없습니다. **켤 때마다 자동으로 최신 버전**을 받아 옵니다. 설정창 아래쪽에 `최신(raw)` 처럼 표시됩니다.

**Q. 오류로 꺼졌다는 창이 떠요.**
`C:\Users\(내 이름)\AppData\Local\ticker\error.log` 파일을 댓글이나 쪽지로 보내 주시면 고쳐 드리겠습니다.

**Q. 지우고 싶어요.**
1. 위젯을 끕니다(오른쪽 클릭 → 닫기).
2. `RealtimeTicker.exe` 와 바로 가기를 지웁니다.
3. `윈도우키 + R` → `%LOCALAPPDATA%\ticker` 입력 → 열린 폴더를 통째로 지웁니다. (내 종목 목록·위치 설정이 여기 있습니다)

설치 프로그램이 아니라서 '프로그램 추가/제거'에는 나오지 않습니다. 위 3단계면 깨끗이 지워집니다.

### ⚠️ 알아 두실 점
- 시세는 무료 공개 데이터라 **증권사 화면과 몇 초 차이**가 날 수 있습니다. 매매 판단은 증권사 화면으로 해 주세요.
- 분배금 공지판은 운용사 홈페이지 공지를 자동으로 읽어 오는 것이라, 운용사가 홈페이지를 바꾸면 잠시 늦거나 빠질 수 있습니다. **정확한 금액·날짜는 공지 원문**(칸을 누르면 열립니다)으로 확인해 주세요.
- 개인이 취미로 만든 프로그램이라 투자 결과에 대한 책임은 지지 않습니다.
