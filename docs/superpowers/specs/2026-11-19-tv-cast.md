# LG TV 자막 전송 설계

사용자가 승인한 구성: Windows에서 동영상과 외부 자막을 선택하고, 자막을 영상에 합친 다음 같은 네트워크의 LG TV로 전송한다. 원본은 보존한다. 변환 후 재생하여 실시간 변환 부하를 피한다.

Node.js 기본 모듈과 기존 FFmpeg를 사용한다. 로컬 브라우저 UI, Windows 파일 선택창, SSDP TV 검색, UPnP AVTransport 재생, HTTP 바이트 범위 전송으로 구성한다. 변환 결과는 OS 임시 폴더에 두고 공개 저장소에는 넣지 않는다. SRT/SMI/ASS 및 한국어 자막을 지원한다. 1080p H.264/AAC MP4로 변환하고 준비된 파일은 재사용한다.

화면에는 진행률, 마지막 확인 시각, TV가 실제로 영상을 요청한 시각, 오류를 표시한다. TV 명령 수락과 실제 화면 확인은 구별한다. 종료 시 변환과 서버를 정리한다. 검증은 로컬 HTTP 범위 요청, SOAP 모의 TV, 실제 FFmpeg 자막 합성으로 수행한다. 실제 TV의 자막·소리는 사용자 확인 전까지 미확인이다.
