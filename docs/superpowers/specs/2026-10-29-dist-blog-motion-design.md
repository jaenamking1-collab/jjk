# 분배금 공지 사이트 — 네이버 블로그 소개글 + 모션그래픽 설계

2026-10-29 · 집 PC · 사용자와 대화로 정함

## 왜 만드나
월배당 ETF 투자자는 늘 세 가지를 궁금해한다.
1. **언제 나오지?** — 지급일
2. **언제까지 사야 받지?** — 분배락 전날까지 매수
3. **얼마 나오지?** — 1주당 분배금

공개 공지 사이트(`https://jjk.distributionjn.workers.dev/`)는 이 셋을 운용사 6곳(KODEX·TIGER·ACE·RISE·PLUS·SOL) 공지에서 자동으로 모아 **달력 한 화면에** 보여 준다.
글을 본 사람이 **"아, 다 정리된 사이트가 있구나. 달력으로 한눈에 보여서 편하네"** 하고 사이트에 들어오는 것이 목표다(사용자 말).

## 목표 / 안 하는 것 / 실패로 보는 것
- 목표: 네이버 블로그 글 1편 — 사이트 소개, 실제 화면 스샷, 실제 사용 모습, 모션그래픽.
- 안 하는 것: 유튜브 쇼츠(사용자가 정정 — 블로그 안에 넣을 영상만). 기술 이야기(파서·자동화)는 한두 줄로만 넣는다.
- 실패로 보는 것:
  - 사용자 개인 계좌·보유 종목·금액이 한 칸이라도 나오는 것. 공개 페이지에는 보유 개념이 없으니 **공개 페이지만** 찍는다. 개인 앱(`portfolio.html`)은 쓰지 않는다.
  - 화면 속 날짜·금액이 실제 운용사 공지와 다른 것. 영상과 스샷에 쓰는 숫자는 실제 응답(`dist_snapshot.txt` 또는 공개 주소)에서 가져오고, 한 종목 이상은 운용사 원문과 대조한다.
  - 투자 권유처럼 읽히는 것("이 종목 사세요"). 특정 종목 추천 문구는 넣지 않는다.

## 결과물
1. **블로그 본문 초안** (`blog/2026-10-dist/본문.md`) — 네이버 에디터에 붙여 넣기 좋은 짧은 문단. 구성:
   - 도입: "월배당 ETF, 언제 나오고 언제까지 사야 하는지 헷갈리시죠?"
   - 세 질문에 하나씩 답하기. 각 답마다 해당 화면(스샷 또는 GIF)
   - 탭 소개: 달력 / 분배금공지 / 분배일정 / 종목전체, ★ 관심만·🙈 숨김
   - 실제 사용 모습: 방문자가 달력에서 이번 주를 넘겨 보고, 관심 종목만 골라 보는 흐름
   - 마무리: 사이트 주소 + "공지는 30분마다 갱신" 정도의 한 줄
2. **스샷 4~6장** — 공개 주소를 실제 크롬으로 찍는다(PC 폭 + 휴대폰 폭 1~2장).
3. **모션그래픽 mp4 1편** — 15~30초, 16:9(네이버 본문 폭), prompt-motion.com 의 'Product UI' 형태.
   - 흐름(내 판단): 질문 문구 등장 → 달력 화면이 떠오름 → 지급일 칸 강조 "여기가 지급일" → 분배락 전날 칸 강조 "이날까지 사면 받아요" → 금액 칸 확대 "1주당 ○○원" → 사이트 주소로 끝.
   - 화면은 실제 사이트를 본뜬 HTML(같은 색·글꼴)로 만들고, 가상 시계로 프레임을 찍어 ffmpeg 로 mp4 를 굽는다(이전 '디자인 영상 → mp4' 방식).
4. **GIF 2~3개** — mp4 의 핵심 장면(지급일·분배락·금액)을 잘라 본문 중간에 넣는다. 네이버는 GIF 가 저절로 움직이고 mp4 는 눌러야 재생된다. 네이버 GIF 용량 제한은 만들 때 확인한다.

## 정해진 것
- 올릴 곳: 네이버 블로그(사용자 계정).
- 영상 스타일: 사용자가 따로 고른 것이 없어 **내가 고른다** — 공지 사이트와 같은 색·글꼴의 깔끔한 Product UI.
- 글은 내가 쓴다. 게시는 처음엔 **사용자가 직접 붙여 넣는다**(한 편이면 그게 가장 싸다). 정기 글로 이어 가면 그때 Aside 자동 게시를 붙인다(Aside 규칙 4번 '블로그 자동 글쓰기 금지'는 그때 바꾼다).

- 소리: 넣지 않는다(내 판단 — 블로그는 대부분 소리 끄고 본다). 설명은 화면 글자로만.

## 만드는 사람에게 맡기는 것

- 글꼴·여백·전환 효과의 세부.
- 파일 위치: `blog/2026-10-dist/`. `jjk` 는 **공개 저장소**라 사진·영상도 공개된다 — 공개 페이지 화면뿐이라 괜찮지만, 큰 mp4·프레임 PNG 는 `.git/info/exclude` 로 빼고 최종본만 사용자에게 보낸다.

## 확인 방법
- 스샷·영상 속 날짜·금액 1개 이상을 운용사 원문과 대조한 결과를 사용자에게 같이 준다.
- 완성된 mp4·GIF 를 실제로 재생해 첫 장면·중간·끝 프레임을 확인한다.
- 사용자가 네이버에 올린 뒤 휴대폰 화면에서 GIF 가 움직이는지 본다(사용자 확인).
