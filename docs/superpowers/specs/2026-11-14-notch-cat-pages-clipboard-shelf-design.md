# 노치 고양이: 쪽 정리 · 물방울 설정 · 클립보드 · 파일 선반 · 휴대폰 보내기 · Tab 넘기기

2026-11-14, 사용자와 정함. 대상: `notch-cat/` (Rust 윈도우 노치 앱).

## 왜

쪽(음악·시세·날씨·달력·AI)이 늘어 정리가 필요하고, 사용자는 노치 하나에서 "복사한 것·올려 둔 파일을 껐다 켜도 잃지 않고 꺼내 쓰기"를 원한다.
설정은 지금 오른쪽 클릭 메뉴와 따로 뜨는 창에 흩어져 있다 → 노치 안 물방울로 모은다.

## 정한 것 (사용자)

1. **Tab 으로 쪽 넘기기** — 노치가 펼쳐져 있고 마우스가 그 위에 있을 때만 Tab 다음 쪽, Shift+Tab 앞 쪽. 그 밖에서는 Tab 을 건드리지 않는다.
2. **오른쪽 물방울 설정 칸** — 쪽마다 ⚙ 단추, 누르면 노치 **오른쪽**으로 일정 칸과 같은 물방울(오목한 목으로 이어진)이 흘러나온다. 맨 위 쪽 점 옆 ⚙ 은 공통 설정.
   - 공통: **메뉴 정리**(쪽 칩을 눌러 켜고 끄기 · 끌어서 순서, 꺼진 쪽은 넘길 때 건너뜀, 마지막 하나는 못 끔, 맨 앞이 처음 쪽, settings.json 저장), 전체 화면일 때 숨기기, 자동 실행, 비켜 놓기, 얼굴 바꾸기.
   - 오른쪽 클릭 메뉴는 '설정 열기'·'끝내기'만 남긴다(6단계).
3. **클립보드 쪽** — 왼쪽 '최근': 복사할 때마다 자동으로 받아 적어 10개(넘으면 오래된 것부터 빠짐). 오른쪽 '고정': ☆ 로 옮긴 것 10개까지, ✕ 로 뺌. 둘 다 미리보기(글자 앞부분 · 그림 작은 그림). 누르면 클립보드에 다시 넣음(붙여 넣기는 사용자가 Ctrl+V). 껐다 켜도 남는다(노치 자료 폴더에 파일로).
4. **파일 선반 쪽** — 파일·폴더를 끌어다 놓으면 **경로를 기억**(원본은 그대로). 끌어 내리면 놓는 곳에 따라: 탐색기·바탕화면 = 늘 **복사**(이동 금지), 프로그램 창(한글 등) = 그 프로그램이 연다. 두 번 누르면 기본 프로그램으로 열기. 끌고 오면 노치가 펼쳐지며 받는 칸이 빛나고, 놓으면 물방울이 받아먹는 효과 + 고양이 좋아하는 얼굴. 클립보드의 그림을 끌어 내리면 그림 파일로 놓인다.
5. **휴대폰으로 보내기** — 같은 와이파이. 노치가 작은 내려받기 주소를 열고 QR 을 띄운다 → 휴대폰 카메라로 찍어 브라우저에서 받음. 앱 설치 없음. 처음 한 번 방화벽 '허용' 클릭은 사용자.
6. **나머지 설정 옮기기** — 음악 모양, 시세(한 줄·두 칸·종목 목록), 달력(계정·모양)을 각 쪽 물방울로. 시세 종목 창이 가장 크니 마지막.

순서: 1 → 2 → 3 → 4 → 5 → 6. **단계마다 main 푸시 → 정식 판 설치 → 확인**해서 바로 쓰게 한다.

## 하지 않는 것 / 지킬 것

- 비밀번호 관리 프로그램이 "기록하지 말라" 표시(`ExcludeClipboardContentFromMonitorProcessing`, `CanIncludeInClipboardHistory`=0)를 붙인 복사는 저장하지 않는다.
- Win+V 기록을 읽지 않는다(기록 기능이 켜져 있어야만 되고 꺼지면 지워진다) — 노치가 직접 복사를 지켜본다(`AddClipboardFormatListener`).
- 선반은 경로만 기억하므로 원본을 옮기거나 지우면 그 칸은 흐리게 '없음' 표시.
- 열린 한글 파일을 복사하면 마지막 저장본이 복사된다(사용자에게 설명함).
- 클립보드·선반 내용은 이 PC 자료 폴더(%APPDATA%\notch-cat)에만, 저장소에 올리지 않는다.

## 방법 (내 판단)

- 그리기·누르기·끌기는 지금 노치의 `Hit`·`hits`·스프링 방식을 그대로 쓴다. 따로 창을 띄우지 않는다(사용자: 노치 안에).
- 쪽 순서·켜짐은 `Cfg` 에 `pages: Vec<(usize, bool)>` 로, `turn()` 은 켜진 것만 돈다.
- 파일 받기는 OLE `RegisterDragDrop`(IDropTarget), 내보내기는 `DoDragDrop` 에 CF_HDROP · 효과는 COPY 만.
- 휴대폰은 노치 안 작은 HTTP 서버(같은 망, 한 번 쓰는 짧은 주소 + 몇 분 뒤 닫힘), QR 은 직접 그린다.
- 화면 확인은 `NOTCH_CAT_SHOT` + 시험용 환경변수(진짜 마우스 금지, notch-cat/CLAUDE.md).

## 빌더에게 남긴 것

물방울 크기·칩 모양·미리보기 칸 크기, 클립보드 그림 저장 형식(PNG 권장), 서버 포트, QR 구현 세부.
