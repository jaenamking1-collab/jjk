# 폰 전용 화면 `m.html` 설계

작성일: 2026-08-13

## 배경

`portfolio.html`은 데스크톱 폭을 전제로 짜여 있다. 2026-08-13에 `@media (max-width:768px)` 한 블록으로
합산 카드와 재남/은경 카드를 응급 처치했지만(WORKLOG 96), 종목관리 표는 열이 13개라 폭 규칙만으로는
답이 없다.

사용자 결정: **폰 전용 화면을 별도 파일로 만든다.** 같은 파일 안에서 분기하는 안(로직 1벌 유지)을
제안했으나 사용자가 별도 파일을 재차 지시했다. 그 결정에 따른다.

## 요구사항

- 폰에서 **PC와 같은 일**을 할 수 있어야 한다(조회 + 편집). 축약된 읽기 전용 뷰가 아니다.
- 넓은 표는 **핵심 열만 보이고, 행을 탭하면 나머지가 펼쳐진다.**
- PC용 `portfolio.html`을 폰으로 열면 **자동으로 `m.html`로 이동**한다.

## 구조

### 파일

저장소 루트에 `m.html`. GitHub Pages가 이 저장소를 그대로 서빙하므로
`https://jaenamking1-collab.github.io/jjk/m.html`로 열린다. 배포 설정 추가 없음. `git push` = 배포.

### 인증 — 재로그인이 필요 없다

`portfolio.html`과 **같은 오리진**이므로 `localStorage`를 공유한다. (94)에서 만든 지문 `jjk_pw_v1`을
`m.html`이 그대로 읽으므로:

- 폰에서 비밀번호를 **다시 등록할 필요가 없다**.
- 지문 빠른 경로(비번 입력 → 즉시 화면)가 **첫 진입부터** 적용된다.

게이트 코드(`_pwHash`/`pwSaveLocal`/`pwVerifyLocal`/`relockGate`/`submitGate`)를 그대로 가져온다.
스냅샷 키는 화면 구조가 달라 재사용이 위험하므로 **별도 키 `jjk_msnap_v1`**을 쓴다.

### 자동 이동

`portfolio.html` 최상단에서 화면 폭이 768px 이하이고 `?pc=1`이 없으면 `m.html`로 이동한다.
`m.html`에는 "PC 화면으로" 링크를 두어 `portfolio.html?pc=1`로 빠져나갈 수 있게 한다.

게이트보다 **먼저** 판정해야 비밀번호를 두 번 묻지 않는다.

### 데이터

`portfolio.html`과 **같은 백엔드, 같은 액션**을 쓴다. 새 백엔드 작업 없음 → **Apps Script 재배포 불필요.**

| 항목 | 값 |
|---|---|
| 부팅 | `getBootstrap` → `{ rate, accounts, holdings, dividends, divsAll, stockList, alerts }` |
| 시세 | `getLivePrices` → `{ prices: { TICKER:{current,change} } }`, 실패 시 `getSheetData` 폴백 |
| 쓰기 | `addHolding`/`updateHolding`/`deleteHolding`/`saveDividend` (기존 그대로) |

`api()`/`apiPost()` 두 함수와 `API` 상수를 그대로 가져온다(약 30줄).

## 화면

### 하단 탭바

폰은 세로가 귀하므로 상단 메뉴 대신 하단 고정 탭바 4개를 쓴다.

```
  홈     종목    분배금   더보기
```

- **홈** — 총 합산(투자금/평가금/손익/연간분배금/누적분배율/환산분배율) + 재남/은경 + 계좌 목록
- **종목** — 보유 종목. 핵심 3열 + 탭하면 펼침
- **분배금** — 월별 분배금 조회·입력
- **더보기** — 대시보드 · 연금플랜 · 분배금공지 · 은경 저축 · 월배당 스크리너 목록

### 표 규칙 (전 화면 공통)

핵심 열만 보이고 행을 탭하면 아래로 펼쳐진다.

```
종목        평가금       손익
▸ TIGER…   99,236,900   +4.9%
▾ KODEX…   10,217,785   +1.5%
   수량 1,200주 · 평단 8,515
   현재가 8,640 · 전일 8,602
   연분배율 12.1% · 월배당
   [수정] [삭제]
```

## 단계

| 단계 | 범위 |
|---|---|
| 1차 | 게이트 + 자동 이동 + 하단 탭바 + **홈 · 종목 · 분배금** |
| 2차 | 대시보드 · 분배금공지 · 연금플랜 · 은경 저축 · 스크리너 |
| 제외 | **엑셀** — 파일 import/export라 폰에서 쓸 일이 없다 |

## ⚠️ 가장 큰 위험: 계산식 중복

**평가금액·손익은 서버가 주지 않는다. 브라우저가 계산한다.** (`renderAccountStats`, `portfolio.html:1365`)
따라서 같은 계산식이 두 파일에 존재하게 된다. 레이아웃이 어긋나면 눈에 보이지만
**숫자가 어긋나면 안 보인다.** 이것이 이 설계의 유일한 실질적 위험이다.

중복되는 계산 — **고칠 때 반드시 양쪽 다 고칠 것**:

| 계산 | 식 | 원본 |
|---|---|---|
| 투자금 | `Σ toKrw(avg_price × quantity)` | `portfolio.html:1390` |
| 평가금 | `Σ toKrw((현재가 ?? avg_price) × quantity)` | `portfolio.html:1391` |
| 손익 | `평가금 − 투자금`, 률 = `손익/투자금×100` | `portfolio.html:1408` |
| 분배금 | `Σ toKrw(amount)` | `portfolio.html:1400` |
| 누적분배율 | `분배금/투자금×100` | `portfolio.html:1410` |
| 환산분배율 | `projectAnnualDist()` 합계 / 투자금 × 100 | `portfolio.html:1315` |

`toKrw(v, cur)` = `cur === 'USD' ? v * rate : v`.

완화책:
1. `m.html`의 계산 블록을 **한 곳에 모으고** 위 표를 주석으로 박아 둔다.
2. `CLAUDE.md`에 `dist_notice.html`과 같은 등급의 미러 경고를 추가한다.
3. 검증 시 **같은 데이터로 두 파일의 합계가 일치하는지** 직접 비교한다.

## 검증

로그인이 필요하므로 브라우저 자동화로는 실데이터를 못 본다. 대신:

1. 375×812로 렌더 — 칸 넘침 0건, 페이지 가로 밀림 없음, 탭바가 내용을 가리지 않음
2. 계산 함수를 떼어내 **같은 입력에 대해 `portfolio.html`과 같은 값**이 나오는지 대조
3. 자동 이동이 게이트보다 먼저 도는지 (비밀번호를 두 번 묻지 않는지)
4. 지문 `jjk_pw_v1` 재사용 확인 — 폰에서 재등록 없이 통과
