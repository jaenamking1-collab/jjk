# 블로그 운영 계획 (네이버 블로그)

## 결정된 것 (2026-09-14)
- **플랫폼**: 네이버 블로그. 이유 — 국내 검색 유입이 목적이고, "월배당 ETF 분배금" 류
  검색어는 네이버가 압도적이다. Workers 정적 페이지는 색인이 거의 안 된다.
- **다루는 프로그램**: ① 분배금공지 ② 시세위젯 ③ 메모장 ④ (나중) 컴시간 경민이

## ⚠️ 에이전트가 할 수 있는 것 / 없는 것
- **할 수 있는 것**: 글 초안 작성, 제목·키워드 설계, 이미지에 넣을 캡처 지점 지정.
- **못 하는 것**: 네이버 블로그에 직접 발행. 네이버 로그인·글쓰기 API 접근 수단이 없다.
  → 이 폴더의 `.md` 를 **사용자가 복사해 스마트에디터에 붙여넣는다.**
  (붙여넣을 때 `**굵게**` 같은 마크다운 기호는 안 먹으므로, 초안은 **줄글 + 소제목** 위주로 쓴다.)

## 운영 규칙
- **1편은 분배금공지로 시작한다.** 넷 중 유일하게 공개 주소가 있어 글에서 바로 링크가 되고,
  검색 수요(“ETF 분배금 지급일”, “TIGER 분배금 공지”)가 가장 크다.
- **주 1편**이면 충분하다. 몰아 쓰고 끊기는 것보다 낫다.
- **이미지는 직접 캡처해서 올린다.** 글자만 긴 글은 네이버에서 잘 안 뜬다.
- **다른 데서 퍼온 문장을 붙여넣지 않는다.** 유사문서로 걸리면 그 글은 검색에서 사라진다.
- 각 글 끝에 **공개 페이지 링크 한 줄**: https://jjk.distributionjn.workers.dev/
